# Brand assets

| File | Use |
|---|---|
| `logo.png` | The README / Marketplace logo — white mark on GitHub's dark canvas (`#0d1117`), rounded, so it reads correctly on both light and dark themes. 1344×525. |
| `logo-dark.png` | Transparent, white ink — for dark backgrounds (docs sites, slides). 1200×381. |
| `logo-light.png` | Transparent, navy ink — for light backgrounds. 1200×381. |

All three are derived from one source, cropped to the mark with 5 % padding, exported at 2× the README display width, and palette-quantized (≈ 17 KB each). The green `+` and red `−` accents are kept in every variant.
